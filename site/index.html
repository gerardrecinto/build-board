build-board

What to build first, what a change forces you to rebuild, and one page that shows it.

For SDKs made of many modules that depend on each other. You list the modules in one JSON file. It orders the builds, finds the rebuild set for a change, flags failed builds, low coverage and wrong SDK tags, and writes a static page.

Output of the commands on the sample manifest in the repo. The module names are made up.





Limits


It reads a manifest you write: it does not run builds or talk to Jenkins, Gerrit or Perforce. It reads line coverage from Cobertura XML or lcov, and does not run or read Klocwork or Parasoft. Full list.
